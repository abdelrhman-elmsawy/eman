# Eman Mohamed — Full Stack .NET Developer Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript, using a warm beige, cream, and coffee-brown visual theme.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and small interactions
- `profile.png` — cropped profile photo from the profile screenshot supplied in the conversation
- `Eman_Mohamed_Mosad_CV.pdf` — CV download linked from the homepage

## Run locally
Keep all files in this folder together, then open `index.html` in a browser. No build tools or installation are required.

## Before publishing
Check the contact details and replace placeholder social links with the correct public profile URLs. Only add real project screenshots and demo links when they are available and safe to share.
