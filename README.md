# Eman Mohamed Mosad — Portfolio

An editorial-minimal portfolio built with plain HTML, CSS, and JavaScript. The visual direction uses a near-white canvas, ink typography, and a lime accent to keep the interface calm, clear, and contemporary.

## Files
- `index.html` — semantic page structure and CV-aligned portfolio content
- `style.css` — responsive layout, editorial typography, project visuals, and motion
- `script.js` — mobile navigation, scroll reveal, and current-year footer
- `profile.png` — profile portrait
- `Eman_Mohamed_Mosad_CV.pdf` — CV download

## Run locally
Keep all files together and open `index.html` in a browser. No build step or package installation is required.

## Design and implementation notes
- Responsive from mobile through desktop layouts.
- Uses IntersectionObserver for subtle section reveals, with a reduced-motion fallback.
- Includes keyboard focus states, a skip link, semantic landmarks, and an accessible mobile menu.
- Project visuals are illustrative concepts, not claims of finished product screenshots.
- No fabricated testimonials, metrics, live demos, or repository URLs are included.
- The LinkedIn link and email are retained from the existing portfolio. The GitHub link points to this portfolio repository.
